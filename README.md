# 🕊️ Cooling-off Box — Emotional Decision Simulator

**Cooling-off Box** is a lightweight web application designed to help individuals pause before making impulsive decisions when emotions run high (anger, over-excitement, panic, or anxiety). It features a locked cooling timer, Socratic reflection questions, and a Clarity Score calculation to evaluate emotional bias.

---

### 🌟 Key Features

* **4 Emotion Modes & Socratic Questions:** Tailored reflection questions designed for specific emotional states (Anger, Over-excitement, Panic, and Anxiety)[cite: 1].
* **Locked Cooling Timer:** Prevents hasty decisions until your reflection period completes[cite: 1].
* **Clarity Score Calculation:** Evaluates emotional bias and provides actionable recommendations[cite: 1].
* **Absolute Privacy (Client-side Only):** All decisions and logs are stored exclusively on your device via `localStorage`. Zero data is sent to external servers[cite: 1].
* **Multilingual Support:** Built-in support for English and Indonesian[cite: 1].
* **Dynamic & Responsive Theme:** Light and Dark theme toggling with adaptive ambient background gradients[cite: 1].
